# GATE 2027 Preparation Tracker

A robust, self-contained React application designed to help track preparation for the GATE 2027 exam.

## Features

- **Dashboard**: High-level overview with deadline-based alerts.
- **Syllabus Tracking**: Track your progress across different subjects.
- **Study Log**: Maintain a daily record of study hours and topics covered.
- **Test Scores**: Visualize and track mock test performance.
- **Mistake Tracker**: Log and review mistakes to improve performance.
- **Privacy First**: Uses `localStorage` to keep your data private and local to your device.
- **Dark Theme**: Modern, responsive dark-themed UI.
- **Accurate Timing**: IST-anchored date handling for accurate deadlines.

## Getting Started

This project is built with React and Vite.

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd gate-prep
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the App

To start the development server, run:
```bash
npm run dev
```

### Building for Production

To build the app for production, run:
```bash
npm run build
```

To preview the production build, run:
```bash
npm run preview
```

## Technologies Used

- **React** - UI library
- **Vite** - Build tool and dev server
- **Vanilla CSS** - Styling
